### Elephant Colors

Convert colors between different formats (Hex, RGB, HSL).

#### Features

- Type any color value and get conversions to all other formats
- Supports: Hex (`#ff0000`), RGB (`rgb(255, 0, 0)`), HSL (`hsl(0, 100%, 50%)`), named colors (`red`)
- Copy any converted value with a single action

#### Requirements

- `wl-clipboard` for copy action

#### Usage

Type a color value in any supported format. The provider shows the equivalent values in all other formats. Select one and activate to copy it.
